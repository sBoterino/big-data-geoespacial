# Evidencia — conexión GitHub → smee → Jenkins

Fecha: 4-oct-2026

- Se creó un canal de smee y su URL se guardó únicamente en el `.env` ignorado por Git.
- El servicio `bdgeo-smee-1` inició correctamente.
- El cliente informó que estaba conectado y reenviando hacia
  `http://jenkins:8080/github-webhook/`.
- GitHub creó un webhook activo para eventos `push`, contenido `application/json` y
  verificación SSL habilitada.
- El ping inicial produjo `POST http://jenkins:8080/github-webhook/ - 200` en el log de smee.

La siguiente comprobación es que un push real a `main` cree un build automático en `bdgeo-main`.
